# Python OOP & Programming Practice

A beginner-friendly collection of Python exercises and mini-projects by **Sakshi Manapure**. This repository covers Object-Oriented Programming (OOP), loops, conditions, functions, and problem-solving.

## Repository structure

| File | What you will practise |
|---|---|
| `opp.py` | OOP fundamentals, inheritance, method overriding and polymorphism |
| `laptop_class.py` | Class, object, constructor, attributes and display method |
| `calculator_methods.py` | Instance methods and arithmetic operations |
| `employee_salary.py` | Methods, input validation and annual salary calculation |
| `product_class.py` | Properties, quantity validation and total-price calculation |
| `event_ticket_booking.py` | Object interaction, booking, cancellation and money calculations |
| `daily_task_2026_11_03.py` | Playlist manager, encapsulation and duplicate prevention |
| `daily_task_2026_11_04.py` | Plant-care tracker, properties, date handling and validation |
| `basic_loop_programs.py` | Number patterns, even/odd numbers, natural-number sum, factorial and prime checking using loops and functions |

## Concepts covered

- Classes, objects, constructors (`__init__`), attributes and methods
- Encapsulation and properties
- Inheritance, `super()` and method overriding
- Loops (`for`, `while`) and conditional statements
- Functions, input validation and basic exception handling
- Number logic: even/odd, factorial, prime numbers and summation
- Object interaction and simple mini-project design

## Requirements

- Python 3.9 or later
- No third-party packages are required

## Run a file

Open a terminal in this repository and run the file you want to practise:

```bash
python basic_loop_programs.py
python opp.py
python laptop_class.py
python calculator_methods.py
python employee_salary.py
python product_class.py
python event_ticket_booking.py
python daily_task_2026_11_03.py
python daily_task_2026_11_04.py
```

On Windows, you can use `py` instead of `python`.

### Try the Number Toolkit

Run `basic_loop_programs.py` and choose an option from its menu:

1. Print numbers from 1 to 100
2. Display even and odd numbers
3. Find the sum of natural numbers
4. Calculate the factorial of a number
5. Check whether a number is prime
0. Exit the program

## Learning tip

Run one file at a time, try different inputs, predict the output, and then check your result. You can also add your own functions and test cases as you learn.
