# Python OOP Practice

A Python practice repository for object-oriented programming (OOP). The main script is `opp.py`.

## Practice questions

1. Student information
2. Food order and inheritance
3. Bank account methods
4. Library management
5. Hospital management
6. Online shopping and discount
7. ATM operations
8. Quiz application
9. Employee salary and inheritance
10. Vehicle inheritance
11. Laptop class and calculator methods

## Concepts covered

- Classes and objects
- Attributes and methods
- Constructors (`__init__`)
- Inheritance
- Encapsulation
- Returning values from methods
- Basic arithmetic operations

## Requirements

- Python 3

## Run locally

```bash
python opp.py
```

On Windows, `py opp.py` may also work.

## Learning goal

Run each example, understand the logic, and practise modifying classes, attributes, and methods.
